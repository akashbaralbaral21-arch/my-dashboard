Decisions: if, else, and Comparisons

Teaching your program to choose a path instead of just running straight off a cliff.

🎯 Today's only goal

Build a Movie Ticket Pricer. It asks for a person's age and prints the correct ticket price based on their age group. To do this, you need three new tools:

  • Comparisons — checking if something is bigger, smaller, or equal (>, <, ==)
  • if / else — doing one thing if true, another if false
  • elif — checking multiple conditions in a row

🔍 Key words first

Comparisons > (greater than), < (less than), >= (greater or equal), <= (less or equal), == (exactly equal). These always result in True or False.
if "If this condition is True, run the indented code below me."
else "If the if above me was False, run this instead." (No condition needed, it's the catch-all).
elif Short for "else if". "If the previous if was False, check this new condition."
Indentation Python uses spaces (usually 4) at the start of a line to know what code belongs *inside* an if block. No spaces = not inside the block.

💡 Smallest working example

age = 20

if age >= 18:
    print("Adult")
else:
    print("Minor")
Line 3: Is 20 >= 18? Yes (True). Python runs line 4.
Line 4: Prints "Adult".
Line 5 & 6: Because the if was True, Python completely skips the else block.

✋ Practice rounds

Round 1 — The double equals trap

password = "secret"

# Try changing == to = and see what happens
if password == "secret":
    print("Access granted")

The Rule: = puts a value in a box. == asks "are these two things the same?". If you use = inside an if, Python crashes with a SyntaxError because it doesn't make sense to assign a variable inside a question.

Round 2 — Adding elif for multiple choices

score = 85

if score >= 90:
    print("Grade: A")
elif score >= 80:
    print("Grade: B")
elif score >= 70:
    print("Grade: C")
else:
    print("Grade: F")

Python checks top to bottom. 85 is not >= 90 (False). Is 85 >= 80? Yes (True). It prints "Grade: B" and stops checking. The rest is skipped.

Round 3 — The Indentation Trap

x = 10

if x > 5:
print("Big number")

Run this. It crashes with an IndentationError. Python needs you to press Tab (or 4 spaces) before print so it knows that print statement belongs *inside* the if.

Fix it: Add 4 spaces before print and run again.

⚠️ The only 3 mistakes that bite today

1. Using = instead of ==: if age = 18: crashes. You are asking a question, not putting 18 in a box. Use ==.
2. Forgetting the colon: if age > 18 crashes. Every if, elif, and else line MUST end with a colon :.
3. Forgetting to indent: The code inside the if must be pushed to the right (4 spaces). If it's lined up with the if, Python doesn't know it belongs inside.

🚫 Do NOT learn today

  • Boolean logic (and, or, not) — that is Day 4
  • Nested ifs (an if inside an if inside an if) — keep it flat today
  • match / case statements (Python's newer switch statement)
  • Loops (we still aren't repeating things yet)

✅ Check your understanding

1. What is the difference between = and == ?

= puts a value in a box (assignment). == asks if two things are the same value (comparison).

2. If I have an if, an elif, and an else, and the if is True, what happens to the elif and else?

They are completely skipped. Python runs the first True block it finds and then jumps out of the whole structure.

3. Why did Round 3 crash with an IndentationError?

Python uses spaces at the start of the line to group code. Without spaces, it didn't know the print statement belonged inside the if block.

4. What symbol do you use to check if a number is 10 OR MORE?

>= (greater than or equal to).
